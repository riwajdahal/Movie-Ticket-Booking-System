# Movie Ticket Booking System

## Description
The Movie Ticket Booking System is a web application that allows users to browse movies, view showtimes, select seats, and book movie tickets online. Users can also view their booking history and manage their reservations.

The admin can manage movies, showtimes, bookings, and user data for smooth system operation.

---

## Features

### User Features
- Browse movies  
- View showtimes  
- Select seats and book tickets  
- View booking history  
- Manage reservations  

### Admin Features
- Manage movies  
- Manage showtimes  
- View all bookings  
- View users data  
- Dashboard for system overview
